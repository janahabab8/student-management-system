# Student Management System

A JavaFX desktop application for managing student records and grades.
It calculates averages, letter grades and GPA, and generates student reports.

## Features
- Login screen
- Dashboard for navigating between screens
- Add students (ID, name, major)
- Add grades per student and course
- View all students in a table with search and total count
- Generate a report for one student or for all students:
  average, letter grade, GPA, and Pass/Fail status
- Data stored in local text files

## Technologies
- Java 11
- JavaFX 21 (FXML, CSS)
- Maven

## How to Run
1. Install JDK 11 or later and Maven.
2. Clone the repository.
3. Run `mvn javafx:run` from the project folder.
4. Log in with the demo account: `admin` / `1234`.
